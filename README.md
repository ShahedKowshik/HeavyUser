# HeavyUser — original application (historical archive)

> **This is not the current HeavyUser application.** This branch preserves the original multi-purpose productivity app developed December 2025–January 2026. The modern habit tracker is maintained on the [main branch](https://github.com/ShahedKowshik/HeavyUser).
>
> The original **228 commits**, author dates, file history and original README remain available at the unchanged [`legacy-original-v1` tag](https://github.com/ShahedKowshik/HeavyUser/tree/legacy-original-v1). This branch has later explanatory documentation, added without modifying those original historical snapshots.
