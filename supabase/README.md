# HeavyUser database migrations

These 15 migration files were restored verbatim from the live Supabase project's `supabase_migrations.schema_migrations` table on 2026-10-29, then added to GitHub to preserve the exact schema evolution.

The live database already contains these migrations. **Never apply them again to the existing project.** The files are a historical record and a starting point for constructing a new empty development database if that is ever necessary. New changes should be added as new versioned migrations and tested before deployment.

No data rows, user identities, credentials, or environment-variable values are included here. Existing development and production currently share the same live database.
